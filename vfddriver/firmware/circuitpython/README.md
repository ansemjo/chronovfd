# CircuitPython Driver

These `code_*.py` files can be used on a [CircuitPython board](https://circuitpython.org/downloads) to drive the display over I2C. I've used a QT Py ESP32-S3 for most of these.

You may need to install extra libraries for some of these. Use `circup` to do so:

```
circup install asyncio adafruit_connection_manager adafruit_ntp
```
