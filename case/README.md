# chronocase

This is a small collection of 3D-printable cases designed in [Solvespace](https://solvespace.com/) to go with the chronovfd display.

* **chronocase_thinner**: fits a vfddriver v2 display from behind; screw with M2.5 directly into the plastic and use something like a [QT Py ESP32-S2](https://learn.adafruit.com/adafruit-qt-py-esp32-s2/overview) to drive it. This one hides most of the PCB and has a cutout for the vacuum tube
* **chronocase_frontmount**: another variant which takes any of the display PCBs from the front; held in with M2.5 screws and nuts that need to be pushed into pockets. The deep one is suitable for the vacuum tube, while the shallower one features a closed back. The latter is specifically for use with the lcddriver, which is driven from a coin cell and needs no additional driver chips.
